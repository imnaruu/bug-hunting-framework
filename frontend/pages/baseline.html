🔍 Error Pattern Mapping

Identified Error Behaviors:

1. SQL Error Disclosure HIGH RISK
Trigger: Special characters in search parameter (', ", \)
Response: 500 Internal Server Error Body: "Error: ER_PARSE_ERROR: You have an error in your SQL syntax..." Time: 1,245ms (significantly above baseline)
Testing Opportunity: SQL injection likely. Error messages reveal database type (MySQL).
2. Path Traversal Response MEDIUM RISK
Trigger: ../ sequences in file parameter
Response: 403 Forbidden Body: "Access denied to path: /etc/passwd" Time: 112ms (normal)
Testing Opportunity: File path validation exists but may be bypassable.
3. Template Engine Errors MEDIUM RISK
Trigger: Template syntax in user input ({{ }}, ${ })
Response: 500 Internal Server Error Body: "ReferenceError: username is not defined" Time: 567ms
Testing Opportunity: Server-Side Template Injection (SSTI) potential.

  3. CSRF (cookie issues)
