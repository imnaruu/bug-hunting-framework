🔑 Insecure Direct Object Reference (IDOR) Testing

IDOR Testing Methodology:

Step 1: Identify Object References
Look for numeric IDs, UUIDs, or predictable patterns in URLs and API calls:
/api/user/123/profile /documents/download?id=456 /invoice/view/789
Step 2: Test Authorization
Modify object references to access other users' resources:
# Your user ID: 123 # Try: /api/user/124/profile # Try: /api/user/1/profile (admin?)
