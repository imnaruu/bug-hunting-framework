💡 Initial Risk Hypothesis

High-Priority Attack Vectors:

1. Server-Side Prototype Pollution → RCE CRITICAL
Express.js 4.17.1 vulnerable to prototype pollution (CVE-2022-24999). Could lead to authentication bypass or remote code execution.
Hypothesis: Test parameter pollution in POST requests, especially in authentication and session management endpoints.
2. jQuery XSS via DOM Manipulation HIGH
jQuery 3.4.1 has known XSS vectors through .html() and .append() methods when processing user-controlled data.
Hypothesis: Focus on search, filter, and dynamic content loading features.
3. HTTP Request Smuggling MEDIUM
nginx 1.18.0 + backend server configuration may allow CL.TE or TE.CL smuggling attacks.
Hypothesis: Test Transfer-Encoding and Content-Length header discrepancies.
